# API d’extension

Les points d’extension Pressundo incluent l’enregistrement de types personnalisés et des actions/filters WordPress autour de l’enregistrement, des options, de la sanitization, de la validation et de la migration. Préférez toujours les hooks/interfaces publics à l’accès direct aux services internes.

Le contrat v1 figé est documenté dans [API freeze](/fr/reference/api-freeze).
