# Compatibilité VP_Option

Les déclarations courantes `VP_Option` peuvent rester pendant que l’ancien runtime Vafpress est supprimé. Pressundo conserve les retours fluent historiques audités pendant la 1.0 et rend les champs legacy via le même Design System moderne.

Une page de compatibilité peut aussi recevoir des sections Pressundo modernes : le développeur peut conserver les anciens champs et ajouter Typography, Spacing, etc., sans créer deux designs admin.
