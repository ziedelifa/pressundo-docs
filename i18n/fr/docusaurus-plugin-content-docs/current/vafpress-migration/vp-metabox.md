# Compatibilité VP_Metabox

Les usages courants de `VP_Metabox` et les accessors WPAlchemy fréquents sont fournis par le runtime de compatibilité. Les clés de post meta existantes peuvent rester inchangées tandis que l’interface est rendue par Pressundo.

Pour le nouveau code, préférez [`pu_metabox()`](/fr/metaboxes).
