# Air, Slate & Compact

Pressundo fournit trois skins qui utilisent **exactement le même contrat de champs** :

- **Air** — spacieux, neutre, adapté aux réglages de thèmes.
- **Slate** — plus contrasté, style produit/SaaS.
- **Compact** — plus dense pour les écrans techniques comportant beaucoup de contrôles.

```php
'ui_theme' => 'air', // ou slate / compact
```

La skin ne modifie jamais la sanitization, la validation ni la structure des valeurs stockées.
