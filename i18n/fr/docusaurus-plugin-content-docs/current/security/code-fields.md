# Champs Code, CSS & JavaScript

Ces champs conservent volontairement le texte source, puisque c’est leur fonction. Pressundo normalise et stocke le texte mais **ne l’évalue ni ne l’exécute** pendant la sanitization ou le rendu admin.

Si votre application affiche ou exécute ensuite un code configuré par un utilisateur, il s’agit d’une décision séparée à haut niveau de confiance qui doit être sécurisée selon votre cas d’usage.
