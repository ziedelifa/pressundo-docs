# Protection contre les sauvegardes concurrentes

Les pages d’options et metaboxes incluent une empreinte de révision du stockage. Si un administrateur enregistre un ancien formulaire après qu’un autre processus/utilisateur a modifié les données, Pressundo refuse l’écriture obsolète au lieu d’écraser silencieusement les valeurs plus récentes.

Rechargez l’écran, vérifiez les nouvelles valeurs puis réappliquez votre modification.
