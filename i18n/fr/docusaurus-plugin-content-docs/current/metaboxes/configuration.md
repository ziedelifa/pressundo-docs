# Configuration d’une metabox

Utilisez une `storage_key` stable pour le tableau stocké en post meta. `post_types` peut contenir un ou plusieurs types de contenus. Avant d’écrire, Pressundo vérifie la capability de l’utilisateur, le nonce, les autosaves/révisions, la validation et la révision de stockage.
