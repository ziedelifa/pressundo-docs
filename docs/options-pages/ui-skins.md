# UI skins

Pressundo ships three render skins using the **same field contract**:

- **Air** — spacious, neutral, suited to theme settings.
- **Slate** — higher contrast, product/SaaS feel.
- **Compact** — dense layout for technical screens with many controls.

```php
'ui_theme' => 'air', // or slate / compact
```

A skin never changes sanitization, validation or stored value shape.
