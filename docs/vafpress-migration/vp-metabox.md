# `VP_Metabox` compatibility

Common `VP_Metabox` usage and common WPAlchemy-style accessors are provided by the compatibility runtime. Existing post-meta keys can remain unchanged while the UI is rendered by Pressundo.

For new code, prefer [`pu_metabox()`](/docs/metaboxes).
