# `VP_Option` compatibility

Existing common `VP_Option` declarations can remain while the Vafpress runtime is removed. Pressundo preserves historical fluent setter behavior audited during 1.0 development and renders legacy fields through the same modern UI system.

A compatibility page may also add modern Pressundo sections, letting a developer keep old fields and add new typography/spacing/etc. without two admin designs.
